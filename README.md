# ATOM

Apresentação do trabalho de conclusão de curso sobre a arquitetura distribuída
ATOM para a Fábrica de Software do IFC Campus Blumenau.

Para gerar a apresentação, execute os comandos na raiz do projeto.

```sh
npm ci
npm run build
```

Abra `slides.html` no navegador. O slide **Consenso Raft** inicia o RaftScope
ao entrar, envia um comando após a primeira eleição e permite enviar outros
comandos pelo botão **Enviar comando**.
